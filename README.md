# ShopZone — Amazon-inspired HTML & CSS storefront

A responsive, multi-section e-commerce homepage made with **HTML and CSS only**. There is no JavaScript, backend, package installation, or build step.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the intended typography, connect to the internet so Google Fonts can load. The site still has fallback fonts offline.

## Project structure
```text
ShopZone_HTML_CSS_Enhanced/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## What's included
- Amazon-inspired dark shopping header and navigation
- Search form visual interface and category selector
- Responsive hero banner and category shortcuts
- Delivery/service information strip
- Sale banner and CSS-created product illustrations
- Product cards with price, discount, rating and delivery labels
- Category feature cards, student essentials, under-₹499 section
- Newsletter form interface
- Responsive desktop, tablet and mobile layouts
- Hover states, focus states, accessible labels and semantic sections

## Honest limitations (HTML/CSS only)
- Search does not actually filter products.
- Cart and wishlist are visual only.
- Newsletter form does not submit or store data.
- Product art is drawn with CSS, not real product photography.
- There is no account system, checkout, payment, or database.

These are intentional: HTML structures content and CSS styles it, but dynamic shopping behavior needs JavaScript and, for real accounts/orders/payments, a backend. The project uses a fictional brand and is not affiliated with Amazon.
